# 🏠 Estato Marketplace

Estato is a modern full-stack real-estate marketplace platform inspired by online classified marketplaces.

The platform allows users to discover properties, create property listings, and connect with buyers or sellers.

The project currently focuses on **real estate**, with plans to expand into a multi-category marketplace covering cars, bikes, electronics, furniture, and other products.

---

## 🚀 Features

### 👤 User Management
- User registration and login
- User authentication
- User profile management
- Seller information
- Protected user functionality

### 🏡 Property Listings
- Create property listings
- Edit property listings
- Delete property listings
- Upload property images
- View property details
- Seller details
- Property categories
- Property location

### 🔎 Search & Filtering
- Search properties
- Filter by location
- Filter by property type
- Filter by price
- Filter by bedrooms
- Filter by area
- Browse property categories

### 📱 Responsive UI
- Modern real-estate marketplace interface
- Responsive design
- Desktop and mobile-friendly layouts
